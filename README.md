## 📌 Обо мне

QA-инженер с техническим бэкграундом и комплексной подготовкой по ручному и автоматизированному тестированию. 

**Образование и переподготовка:**
- 🎓 **Томский государственный университет** — профессиональная переподготовка по специальности «Специалист по тестированию ПО» (теория тестирования, Agile, Scrum)
- 🚀 **Яндекс.Практикум** — курс «Инженер по тестированию: от новичка до автоматизатора» (ручное и автоматизированное тестирование на Java)
- 🗄 **Интерактивный курс по SQL** — уверенное владение запросами

**Мой профиль:**
- ✅ **Ручное тестирование** — моя сильная сторона: нахожу неочевидные баги, анализирую требования, составляю полную тестовую документацию (чек-листы, тест-кейсы, баг-репорты)
- ✅ **Технический бэкграунд** — понимаю SDLC, этапы релизного цикла, устройство сетей и логику работы сложных систем
- ✅ **Автоматизация** — разрабатываю автотесты на Java + Selenium + REST Assured, использую паттерны Page Object Model, Step Objects, Builder

# Тестирование API сервиса «Яндекс.Прилавок»

Этот проект — моя учебная работа по ручному тестированию API. Я проанализировала требования, разработала чек-лист, провела тестирование и задокументировала найденные дефекты.

---

## 🎯 Что тестировалось
**Объект:** Бэкенд-часть сервиса доставки и управления корзиной «Яндекс.Прилавок».

**Задача:** Проверить функциональность ключевых эндпоинтов API, включая:
- Добавление продуктов в набор
- Расчёт стоимости и условий доставки курьерской службой «Привезём быстро»
- Получение списка товаров в корзине
- Добавление и изменение позиций в корзине
- Полное удаление корзины

---

## 📋 Что было сделано
1. **Анализ требований** — изучила документацию API и логику работы сервиса.
2. **Составление чек-листа** — 110 проверок для полного покрытия функциональности.
3. **Выполнение тестирования:**
   - Позитивные сценарии (корректные данные, штатные ответы)
   - Негативные сценарии (невалидные параметры, устойчивость сервера)
   - Граничные значения (максимальное количество товаров, предельные суммы, спецсимволы)
4. **Баг-репорты** — описала все найденные проблемы.

---

## 🔍 Использованные техники тест-дизайна
Для лучшего покрытия я применила:
- **Классы эквивалентности** — для группировки входных данных по категориям
- **Граничные значения** — для проверки поведения системы на границах допустимых значений
- **Предугадывание ошибок** — для поиска скрытых проблем на основе типичных ошибок

## 🧪 Postman-коллекция
Для удобства ручного тестирования API я использовала Postman-коллекцию, которая включает все запросы по ключевым эндпоинтам сервиса.

📄 [Скачать коллекцию](./postman/Yandex.Prilavok.postman_collection.json)

### Как использовать:
1. Открой Postman → **Import** → выбери файл `Yandex.Prilavok.postman_collection.json`
2. Установи переменную окружения `{{server_url}}` = `https://{id}.serverhub.praktikum-services.ru/` (тестовый стенд, где id известен после запуска сервера)
3. Отправляй запросы в любой последовательности

Коллекция содержит 18 запросов, покрывающих все основные сценарии работы с API сервиса.

# BUG1 — Ошибка 504 Gateway Timeout через 60 секунд при отправке запроса POST /api/v1/courier/login на авторизацию курьера, если не передан пароль

| | |
|---|---|
| **Приоритет** | 🔴 Критический |
| **Компонент** | API · Курьеры · `POST /api/v1/courier/login` |
| **Окружение** | Учебный стенд `qa-scooter.praktikum-services.ru`, проверено через curl и REST Assured |
| **Дата проверки** | 26.08.2026 |
| **Статус** | Открыт, воспроизводится стабильно |

## Описание

Если в запросе на авторизацию курьера отсутствует поле `password`, сервер не отбивает запрос валидацией, а держит соединение **60 секунд** и отвечает `504 Service unavailable`.

При этом отсутствие поля `login` обрабатывается корректно: `400` с внятным сообщением приходит за 0,09 с. То есть валидация обязательных полей на эндпоинте есть, но поле `password` она не покрывает.

## Шаги воспроизведения

1. Создать курьера: `POST /api/v1/courier` с телом `{"login":"<уникальный>","password":"1234","firstName":"Test"}`
2. Отправить `POST /api/v1/courier/login` с телом `{"login":"<тот же логин>"}` — без поля `password`
3. Засечь время ответа

## Ожидаемый результат

`400 Bad Request` с сообщением `Недостаточно данных для входа` — по аналогии с обработкой отсутствующего поля `login`. Время ответа — доли секунды.

## Фактический результат

`504 Service unavailable` через **60,07 секунды**.

## Доказательства

Четыре запроса на один и тот же эндпоинт, различаются только телом:

| Тело запроса | Код | Ответ | Время |
|---|---|---|---|
| `{"login":"curier_1787730687"}` — нет пароля | **504** | `Service unavailable` | **60,07 с** |
| `{}` — пустое тело | **504** | `Service unavailable` | **60,06 с** |
| `{"password":"1234"}` — нет логина | 400 | `Недостаточно данных для входа` | 0,09 с |
| `{"login":"...","password":"1234"}` — корректное | 200 | `{"id":795957}` | 0,13 с |

Первые две строки — дефект, третья и четвёртая приведены для контраста: сервер умеет и валидировать, и отвечать быстро.

## Влияние

Это не только несоответствие спецификации, но и проблема устойчивости:

- каждый такой запрос занимает соединение на минуту;
- поле `password` отсутствует в запросе тривиально — достаточно оборванной формы или ошибки клиента;
- запросы без пароля не требуют авторизации и не ограничены, поэтому их легко отправить много и исчерпать пул соединений.

Из-за 60-секундных ожиданий полный прогон автотестов растягивается примерно с 4 до 10 минут.

## Автотесты, которые ловят дефект

Репозиторий [samokat-api-autotests](https://github.com/TatyanaKovalewa/samokat-api-autotests):

- `CourierLoginTest#loginRequiresPassword`
- `CourierLoginTest#loginWithEmptyBodyReturnsError`
- `CourierLoginTest#loginWithoutPasswordFieldReturnsError`

Зафиксированы в `.github/known-stand-defects.txt` как известные дефекты стенда: сборку не роняют, но продолжают прогоняться и попадают в [Allure-отчёт](https://tatyanakovalewa.github.io/samokat-api-autotests/).

# BUG3 — Ошибка 404 Not Found при отправке запроса PUT /api/v1/orders/accept/{id} на принятие заказа курьером, если не передан id заказа

| | |
|---|---|
| **Приоритет** | 🟡 Средний |
| **Компонент** | API · Заказы · `PUT /api/v1/orders/accept/:id?courierId=:courierId` |
| **Окружение** | Учебный стенд `qa-scooter.praktikum-services.ru`, проверено через curl и REST Assured |
| **Дата проверки** | 26.08.2026 |
| **Статус** | Открыт, воспроизводится стабильно |

## Описание

У запроса на принятие заказа два обязательных параметра: id заказа в пути и `courierId` в query. **Отсутствие каждого из них обрабатывается по-разному:**

- нет `courierId` → `400` с осмысленным сообщением;
- нет id заказа → `404 Not Found.` от маршрутизатора.

Один и тот же класс ошибки — не передан обязательный параметр — приводит к двум разным кодам ответа в пределах одного эндпоинта.

## Шаги воспроизведения

1. Отправить `PUT /api/v1/orders/accept/?courierId=795957` — без id заказа

## Ожидаемый результат

`400 Bad Request` с сообщением о нехватке данных — так же, как при отсутствии `courierId`.

## Фактический результат

`404 Not Found` с телом `{"code":404,"message":"Not Found."}`.

## Доказательства

| Запрос | Код | Ответ |
|---|---|---|
| `PUT /api/v1/orders/accept/?courierId=795957` — нет id заказа | **404** | `{"code":404,"message":"Not Found."}` |
| `PUT /api/v1/orders/accept/709188` — нет courierId | 400 | `{"code":400,"message":"Недостаточно данных для поиска"}` |
| `PUT /api/v1/orders/accept/999999999?courierId=795957` — id не существует | 404 | `{"code":404,"message":"Заказа с таким id не существует"}` |

Вторая и третья строки контрольные и отрабатывают корректно. Именно вторая строка доказывает, что это дефект, а не сознательное решение: для соседнего обязательного параметра того же запроса сервер отвечает ровно так, как ожидается.

## Влияние

Непоследовательность внутри одного эндпоинта. Клиент, написавший обработку ошибок по одному параметру, получит неожиданный код по другому. Плюс `404 Not Found.` неотличим от ситуации «маршрут не существует».
